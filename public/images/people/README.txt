Портреты людей для страниц памяти.

Имя файла = slug человека из data/people.ts, расширение .jpg
Например: maken-saduakaskyzy.jpg

После добавления файла пропишите путь в поле `portrait` соответствующей
записи в data/people.ts, например:
  portrait: "/images/people/maken-saduakaskyzy.jpg",

Рекомендации: вертикальный кадр (портретная ориентация), лицо в верхней
трети, минимум 700x900 px. Файл кладётся в git — не размещайте здесь фото
без согласия семьи.
