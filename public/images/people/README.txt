Портреты людей для страниц памяти.

ФАЙЛЫ
  <slug>.jpg        — кадрированный портрет, который показывается на сайте
  <slug>-full.jpg   — исходный снимок целиком, храним как архив (нигде не выводится)

Slug берётся из data/people.ts. Например: maken-saduakaskyzy.jpg

  <slug>/NN.jpg     — фотографии для вкладки «Медиа → Фото» (01.jpg, 02.jpg, …),
                      подключаются в media.photos той же записи

ПОДКЛЮЧЕНИЕ
  В нужной записи data/people.ts пропишите:
    portrait: "/images/people/<slug>.jpg",
  Без этого поля показываются инициалы.

КАДРИРОВАНИЕ
  Портрет должен быть поясным: голова и плечи, соотношение сторон 3:4.
  Если оставить кадр в полный рост, в круглом аватаре лицо становится
  неразличимым. Небольшой запас над головой — примерно десятая часть высоты.
  Ориентир по размеру: 700x933, JPEG, качество 88, около 120 КБ.

  Пример обработки (Pillow):
    img = Image.open("исходник.jpg").convert("RGB")
    img.crop((left, top, right, bottom)).save(
        "public/images/people/<slug>.jpg",
        "JPEG", quality=88, optimize=True, progressive=True)

ВАЖНО
  Файлы попадают в git и становятся публичными. Размещайте только те фото,
  на публикацию которых семья дала согласие.
